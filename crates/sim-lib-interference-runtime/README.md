# sim-lib-interference-runtime

Runtime records for coherent interference studies.

The crate projects checked physical problems, sampling planes, evidence,
Tensor-backed phasor fields, and scalar projections into Citizen
read-constructs. Registered Shapes admit the public Problem, Plane, Study,
ProjectionRequest, and Projection values. Decoding re-runs domain, tensor,
evidence, and mask invariants; it does not add a domain parser or a second grid
or tensor representation.
