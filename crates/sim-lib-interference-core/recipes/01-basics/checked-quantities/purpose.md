# Checked quantities

Constructs one valid value of every interference boundary type and prints the
canonical stored values. The phase example demonstrates phase normalization and
does not claim a propagation model or solver.

Scope: these quantities serve a homogeneous, isotropic, three-dimensional
scalar free-field model. They do not imply polarization, impedance,
interfaces, obstacles, or diffraction; amplitude-squared values downstream
are normalized observables, not physical intensity, power, or energy.
